# 새 옷·캐릭터 추가하기

앱에 새 스티커를 넣는 데 필요한 것은 **투명 PNG 한 장**과 **부품 설정 JSON 한 파일**뿐입니다. 파이썬 가공 스크립트를 다시 돌릴 필요는 없습니다.

## 1. 투명 PNG 넣기

가공이 끝난 그림을 여기에 둡니다.

```
siha-dress-book/public/sticker/x4/<id>.png
```

- 배경은 투명이어야 합니다.
- 권장 해상도: 스테이지 크기(360×650)의 4배. 예) 옷 폭이 화면에서 120이면 PNG 폭은 약 480px.
- 흰 칼선 테두리가 있으면 어색하니, 가능하면 떼고 넣습니다.

원본 스캔/시트는 `archive/siha-sticker-original/` 에만 보관하고, 여기서는 복사본만 씁니다.

## 2. 부품 JSON 쓰기

파일을 만듭니다.

```
siha-dress-book/src/sticker/data/parts/<id>.json
```

파일 이름과 `id` 를 같게 하세요. 앱이 `parts/*.json` 을 모두 읽습니다.

### 옷처럼 정해진 자리에 붙는 부품 (최소)

```json
{
  "id": "skirt_example",
  "name": "예시 치마",
  "category": "bottom",
  "layer": "bottom",
  "anchor": "waist",
  "scale": 1,
  "hides": [],
  "src": "x4/skirt_example.png"
}
```

| 칸 | 의미 |
| --- | --- |
| `layer` | `layers.json` 의 레이어 이름. 이 값이 그려지는 순서를 정합니다. |
| `anchor` | `characters/siha.json` 의 앵커 이름. 옷이 붙는 기준점입니다. |
| `scale` | 1이면 PNG 픽셀 ÷ 4 가 화면 크기. 0.8이면 조금 작게. |
| `hides` | 같이 있으면 안 되는 것. 슬롯 이름(`top`, `bottom` …)이면 벗기고, 캐릭터 조각 이름(`feet`)이면 그리지 않습니다. |
| `src` | `public/sticker/` 기준 상대 경로. |
| `front` / `back` | 앞·뒤 조각. `src` 만 있으면 앞면 한 장으로 취급합니다. `back` 의 `layer` 기본값은 `back_hair` (머리 뒤). |
| `connectors` | 손·소매·신발 안 양말처럼 다른 레이어에 얹는 이음 조각. |
| `preview` | 트레이 썸네일용. `true` 이면 스테이지에는 그리지 않습니다. |

`x`, `y`, `w`, `h` 를 생략하면 캐릭터 앵커에 맞춰 자동으로 놓습니다. 위치가 어긋나면 `offset` 이나 조각의 `x`/`y`/`w`/`h` 로 미세 조정하면 됩니다.

```json
{
  "id": "hat_example",
  "name": "예시 모자",
  "category": "head",
  "layer": "hair_acc",
  "anchor": "head",
  "scale": 1,
  "hides": [],
  "src": "x4/hat_example.png",
  "offset": { "dx": 0, "dy": -8 }
}
```

### 원피스 (상의·하의를 벗김)

```json
{
  "id": "dress_example",
  "name": "예시 원피스",
  "category": "dress",
  "layer": "top",
  "slot": "dress",
  "anchor": "torso",
  "scale": 1,
  "hides": ["top", "bottom"],
  "front": [{ "src": "x4/dress_example.png" }],
  "back": []
}
```

`slot` 을 생략하면 `layer` 와 같아집니다. 원피스는 상의와 겹치지 않게 `slot` 을 `"dress"` 로 두는 것이 좋습니다.

### 신발 (맨발 숨김)

```json
{
  "id": "shoes_example",
  "name": "예시 신발",
  "category": "shoes",
  "layer": "shoes",
  "anchor": "feet",
  "scale": 1,
  "hides": ["feet"],
  "front": [
    { "src": "x4/shoes_example-l.png" },
    { "src": "x4/shoes_example-r.png" }
  ]
}
```

이미 맞춰 둔 신발은 맨발 실루엣을 `replacePieces.feet` 로 바꿔, 신발 밖으로 나온 발만 가립니다.

### 여러 자리에 붙는 장식 (리본·꽃)

`anchors` 목록이 있으면 슬롯 없이, 가장 가까운 앵커에 붙습니다. 모든 앵커에서 멀면 떨어뜨린 자리에 그대로 남습니다.

```json
{
  "id": "bow_example",
  "name": "예시 리본",
  "category": "ribbon",
  "layer": "hair_acc",
  "scale": 1,
  "anchors": ["crown", "side", "neck", "waist", "shoe_l", "shoe_r"],
  "src": "x4/bow_example.png"
}
```

손 소품은 `"layer": "hand_prop"`, `"anchors": ["hand"]` 를 쓰면 됩니다.

### 앞·뒤 + 이음 조각

옷이 몸 뒤로 돌아가거나, 소매 밖으로 손이 나와야 하면 **원본 그림에 그 조각이 있을 때만** 나눕니다. 한 장짜리 칼선을 스크립트로 반으로 자르거나 소매를 새로 그리지 마세요. 이음이 보이면 그 조각을 지우고 원본 한 장만 씁니다.

```json
{
  "id": "coat_example",
  "name": "예시 코트",
  "category": "top",
  "layer": "outer",
  "anchor": "torso",
  "scale": 1,
  "hides": [],
  "back": [{ "src": "x4/coat_example-back.png", "layer": "back_hair" }],
  "front": [{ "src": "x4/coat_example-front.png" }],
  "connectors": [{ "src": "x4/coat_example-hand.png", "layer": "arms" }]
}
```

`connectors` 의 `layer` 로 손·양말·발 이음 조각이 어느 겹에 올라갈지 정합니다.

### 트레이 칸에 보이게

`category` 는 `layers.json` 의 `categories` 값 중 하나입니다. `dress`, `top`, `bottom`, `socks`, `shoes`, `head`, `ribbon`, `flower`, `neck`, `charm`.

트레이 순서를 정하려면 `layers.json` 의 `partOrder` 배열에 `id` 를 넣습니다. 없어도 동작합니다.

## 3. 새 캐릭터 추가

1. 몸 그림 PNG 를 `public/sticker/x4/` 에 둡니다. (필요하면 발 조각을 따로)
2. `src/sticker/data/characters/<id>.json` 을 만듭니다. `siha.json` 을 복사해 `id`, `name`, `pieces`, `anchors` 좌표만 바꾸면 됩니다.
3. `src/sticker/model.js` 에서 그 캐릭터 JSON 을 읽도록 한 줄을 연결합니다. (지금은 시하 한 명입니다.)

캐릭터 파일에 꼭 들어가야 하는 것:

- 몸 이미지 (`pieces`)
- 옷·장식이 붙는 앵커 좌표 (`anchors`). 최소 `torso`, `head`, `waist`, `legs`, `feet`, `hand` 를 권장합니다.

뒷머리·얼굴·앞머리를 따로 그리면 `pieces` 에 레이어를 나눠 넣으면 됩니다. 시하 원본은 전신 한 장라서 그 세 겹이 몸 그림에 포함되어 있습니다.

## 레이어 순서 (아래 → 위)

1. 뒷머리 `back_hair`
2. 몸 `body`
3. 속옷 `underwear`
4. 양말 `socks`
5. 신발 `shoes`
6. 하의 `bottom`
7. 상의 `top`
8. 겉옷 `outer`
9. 팔·소매 `arms`
10. 얼굴 `face`
11. 앞머리 `front_hair`
12. 머리장식 `hair_acc`
13. 손 소품 `hand_prop`

## 동작 요약

- 각 조각은 자기 `layer` 에, 표 순서대로 그려집니다.
- 마우스와 터치 모두 끌어다 놓을 수 있습니다.
- **슬롯이 있는 옷** (상의, 하의, 신발 등): 캐릭터 위에 놓으면 정해진 자리에 붙습니다.
- **슬롯이 없는 장식**: 가까운 앵커에 붙고, 멀면 떨어뜨린 자리에 남습니다.
- 신발을 신으면 맨발이 가려지고, 원피스를 입으면 따로 입은 상의·하의가 벗겨집니다.
- 코디는 브라우저에 자동 저장되고, **저장** 버튼으로 PNG 를 받을 수 있습니다.
