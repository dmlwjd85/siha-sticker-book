# 자동으로 부족한 그림 작업

원본은 만지지 않고, 복사본만 `tools/build_sticker_assets.py` 로 가공합니다.

원본 묶음이 `archive/siha-sticker-original/` 에 있고 Real-ESRGAN 모델(`STICKER_ESR_MODEL`)이 있을 때만 **전체 재가공**(칼선 제거·4배 업스케일)이 됩니다. 이 저장소에는 이미 가공된 `public/sticker/` 복사본이 들어 있어 앱은 그대로 돌아갑니다.

코드로 자르거나 다시 그린 그림은 목·손 이음·원본 스타일이 맞지 않으면 **메우지 않고 삭제**합니다. `#dress` 드레스 북과 원본 보관 폴더는 건드리지 않습니다.

## 스크립트가 하는 일 (`build_sticker_assets.py`)

1. **흰 칼선 테두리 제거** (`tools/sticker_fit/rim.py`) — 바깥에서 이어진 흰 띠만 지웁니다.
2. **4배 업스케일** (`tools/sticker_fit/esr.py`) — Real-ESRGAN anime 로 선을 선명하게 키웁니다.
3. **손 이음 조각** — 원본 전신 시트에서 뗀 손은 옷 PNG에 남은 피부·손가락이라 **쓰지 않습니다**. 시하의 손·발이 소매·밑단 구멍으로 비치게 합니다.
4. **속바지 짧게** — 흰 반바지 밑단을 가장 짧은 치마보다 위로 다시 칠합니다. (`fixes.shorten_shorts`)
5. **배경 구멍 메우기** — 모눈종이 PNG 의 스티커 구멍을 같은 모눈으로 메웁니다. (`bgfill`) 검수 후 격자를 깨끗하게 다시 그립니다.
6. **신발 맞춤** — 신발 밖으로 나온 맨발을 가립니다.

`finish_art.py` 는 더 이상 에셋을 만들지 않습니다.

## 품질이 안 되어 삭제한 코드 그림

아래는 가공된 복사본만으로 스크립트가 자르거나 그려 넣었으나, 목·어깨·손에서 이음이 보이거나 원본 스티커와 스타일이 달라 **카탈로그와 PNG에서 제거**한 것입니다.

| 삭제한 것 | 이유 |
| --- | --- |
| 몸 레이어 분리 (`siha-back-hair`, `siha-face`, `siha-front-hair`, `siha-arm-wave`) | 턱·어깨 마스크 이음, 잘린 팔 구멍 |
| 분홍 드레스·노란 상의 소매 이음 (`*-sleeve.png`) | 옷 몸판까지 잘려 팔 레이어에 겹침 |
| 머리 장식 앞·뒤 자름 (`*-front.png`, `*-back.png`) | 정수리 세로 이음, 한쪽이 머리 뒤로 사라짐 |
| 자동 틈 메우기 (`patch-*.png`) | 코드로 채운 조각 |
| 다리 실루엣으로 다시 칠한 양말 (`socks_long.json`, `socks_short.json` 및 칠한 PNG) | 가로줄·발가락까지 다시 칠한 그림. 원본 칼선 양말은 가장자리 흰 띠가 다리 옆으로 나와 카탈로그에도 넣지 않음 |
| 막대사탕 막대 다시 그리기 | 원본과 다른 직선 막대. 사탕 원본 PNG 로 되돌림(칼선 제거 때 막대가 끊긴 상태) |
| 하늘 드레스·곰 우주복 손 이음 (`dress_blue-hand.png`, `onesie_bear-hand.png`) | 원본 시트에서 반쯤 지운 피부·손가락. 옷이 시하 손 위에 앉도록 삭제 |
| 카탈로그에 없는 원본 칼선 양말 PNG | 가장자리 피부·칼선 잔여. 쓰지 않음 |
| 하늘 프릴 드레스 (`dress_blue`) | 이전 코드 그림 원피스. PNG·설정 삭제 |
| 분홍 프릴 드레스 (`dress_pink`) | 이전 코드 그림 원피스. PNG·설정 삭제 |
| 보라 곰 우주복 (`onesie_bear`) | 이전 코드 그림. PNG·설정 삭제 |

몸은 다시 **원본 전신 한 장**입니다. 머리 장식은 원본 칼선 한 장입니다.

옷 PNG에서 원본 시트에 남아 있던 **피부·손가락·발가락·반쯤 지운 팔다리**를 지웠습니다. 소매·목·엉덩이 구멍은 시하 손·목이 비치도록 옷 가장자리만 남겼습니다.

## 원본 묶음이 있어야만 하는 일

아래만 아직 **원본 A/B/C 시트**가 필요합니다. 가공된 한 장짜리 칼선 PNG 만으로는 더 나아지기 어렵습니다.

### 원본 보관

세 묶음 원본 PNG 는 이 저장소에 들어 있지 않습니다. `archive/siha-sticker-original/README.md` 의 목록대로 A/B/C 를 채워 주세요. 원본은 읽기만 하고 수정하지 않습니다.

### 입은 전신 시트에서 떼는 손·뒷자락·머리 앞뒤

하늘 드레스·곰 우주복의 손 조각은 원본 **전신 시트**(옷을 입은 그림)에서 뗐습니다. 분홍 드레스·노란 상의는 칼선 한 장뿐이라 소매 밖 손·뒷자락이 없습니다. 머리 장식을 머리 사이로 감싸려면 앞·뒤가 나뉜 원본이 있어야 합니다. 얼굴·앞머리·뒷머리를 따로 쓰려면 몸 시트가 레이어로 나뉘어 있어야 합니다.

### 양말·막대사탕 막대

양말을 다리에 맞추거나, 막대사탕 막대의 끊긴 부분을 원본 선으로 되돌리려면 묶음 원본(또는 칼선 제거 전 PNG)이 필요합니다.

### 업스케일 모델

Real-ESRGAN anime 6B ONNX 는 저장소에 넣지 않습니다. 재가공할 때만 `STICKER_ESR_MODEL` 로 경로를 넘깁니다.
